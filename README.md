# 付箋マップ

付箋を地図のように広げて、つなげて、整理できるメモアプリです。ホーム画面に追加すると、アプリとしてオフラインでも使えます（PWA）。

公開URL: https://ochakuu8-sudo.github.io/MEMO-app/

## ファイル

- `index.html` … アプリ本体（HTML・CSS・JavaScript を1ファイルに収めています）
- `manifest.webmanifest` … PWA の名前・アイコン・表示方法
- `sw.js` … オフライン用のキャッシュ（Service Worker）
- `icons/` … アプリのアイコン

付箋のデータはブラウザ（端末）の中だけに保存されます。別の端末へ移すときは「その他 → 書き出す（バックアップ）」と「バックアップを読み込む」を使ってください。

## 更新するとき

`index.html` などを変更して push すると、インストール済みのアプリは次に開いたときに裏で新しい版を取り込み、その次の起動から新しい版になります。ファイルを増やしたり減らしたりしたときは、`sw.js` の `SHELL` を直して `VERSION` を上げてください（例: `v1` → `v2`）。
